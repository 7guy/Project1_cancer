### 🩺 AI 기반 암 위험도 판단 헬스케어 서비스

본 프로젝트는 사용자 입력 정보를 기반으로 암 위험도를 판단하는 예방 중심 AI 헬스케어 서비스입니다.
암은 조기 발견이 중요하지만, 일반 사용자가 일상에서 자신의 암 위험도를 사전에 인지하기는 어렵다는 문제의식에서 출발하였습니다.

의료 진단을 대체하는 것이 아닌,
사전 위험 인지 및 생활 습관 개선을 돕는 참고용 서비스를 목표로 기획되었습니다.

#### 프로젝트 개요

- 사용자로부터 기본 정보, 생활 습관, 증상 정보를 입력받아 통합 암 위험도를 1차 분석
- 사용자가 원할 경우 폐암·간암 정밀 판단 모델을 추가로 수행
- 머신러닝 예측 결과를 LLM을 활용해 이해하기 쉬운 형태로 해석 및 안내
- 사용자 입력 흐름에 따라 필요한 정보만 추가 질문하는 인터랙티브 방식 적용

기존 단순 정보 제공형 서비스와 달리,
단계적 분석 구조를 통해 사용자 맞춤형 위험도 판단을 제공하는 것이 특징입니다.

#### 시스템 흐름

- 사용자 기본 정보 및 증상 입력
- 통합 암 위험도 1차 분석
- 사용자 선택 시 폐암·간암 정밀 판단 수행
- 머신러닝 예측 결과 도출
- LLM을 활용한 결과 해석 및 사용자 안내

#### 기대 효과

- 사용자가 자신의 암 위험 요인을 사전에 인지
- 생활 습관 개선 및 건강 관리에 활용 가능
- 병원 방문 전 참고용 판단 자료로 활용 가능
- 머신러닝과 LLM을 결합한 실무 활용 가능 AI 서비스 사례 제시
